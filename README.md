# 反指看板 · Reverse Signal

一个本地优先的观点记录与复盘工具。记录 KOL 的原话、方向和来源，再手动验证结果，查看历史统计。保留趣味证书，但不把历史判错比例说成未来收益或交易胜率。

## 怎么用

1. 下载项目并解压，双击 `index.html`。不需要安装 Node.js，也不需要服务器。
2. 点击右上角“新增观点”，填写名称、标的和方向；也可以粘贴 X / Twitter 链接，点击“识别链接”，核对识别结果。
3. 点击“保存记录”。原话、参考价和来源链接可选填，建议保留验证依据。
4. 在档案的“验证结果”中选择“判对”或“判错”。判断需要修改时，可以重新选择，也可恢复“待验证”。
5. 点击记录旁的铅笔按钮编辑；点击原话展开全文，点击“查看原文”核对来源。
6. 工具栏的向下箭头是“导出备份”，向上箭头是“导入备份”。定期导出，换电脑或浏览器后再导入恢复。鼠标悬停在图标上可查看名称。

## 查找与复盘

- 搜索框可以查找账号、标的、原话、备注、参考价和来源链接，不区分英文大小写。
- 可同时筛选 KOL、标的和验证结果，并按记录时间选择“最新在前”或“最早在前”。清除筛选按钮恢复全部记录。
- 每页最多 25 条，通过列表底部的左右箭头翻页。切换筛选时自动回到第一页。
- 新增保存后会回到全部记录、最新在前，避免新记录被旧筛选条件隐藏。
- 手机和较窄窗口使用逐条记录布局，验证、编辑和删除按钮直接显示，不需要横向滚动。

## 修改与草稿

修改已验证观点的 **KOL、标的、方向、参考价或来源链接** 后，结果自动恢复“待验证”，需要重新判断。仅补充原话/验证备注或清除字段首尾空格时保留原结果。备注字段也允许编辑原话，若这改变了观点含义，请手动把结果改回“待验证”。

点击表单右上角叉号只会收起表单，当前页面的草稿仍保留；新增草稿再次点“新增观点”可继续，编辑草稿再次点同一条记录的铅笔按钮可继续。切换到另一条记录或从编辑转到新增时，未保存修改会先要求确认。刷新或关闭页面时会请求浏览器提示，但浏览器可能限制提示，尤其在手机后台结束应用时。**草稿不落盘，刷新或关闭后不能恢复，请及时保存。**“取消编辑”会明确丢弃当前编辑。

删除一条记录或清空全部后可撤销最近一次删除，恢复原顺序，不覆盖保留记录之后修改的验证结果，也不删除之后导入的记录。撤销只在当前页面有效；再次删除会替换上一条撤销记录，保存新记录或编辑记录后会清除撤销记录。清空异常原始数据不能撤销，必须先备份。

## 统计含义

| 指标 | 含义 |
| --- | --- |
| 已验证样本 | 手动标记“判对”和“判错”的总数，不含待验证 |
| 历史判错比例 | 判错数量 / 已验证数量 |
| 历史判对比例 | 判对数量 / 已验证数量 |
| 反指娱乐星级 | 至少 20 条已验证样本后，按 `round(历史判错比例 × 18)` 折算 |

顶部统计随 KOL、标的和搜索条件变化，不受“待验证 / 判对 / 判错”结果筛选影响，也不受分页影响，避免只查看判错记录时产生虚假的 100% 总体判错比例。证书按选定 KOL 的全部记录生成，不受列表筛选影响；数据变化后证书会重新计算。

**20 条只是娱乐评级的最低展示门槛，不表示统计结论可靠。** 判错比例不是反向交易的胜率；本工具没有验证价格路径、手续费、滑点、持仓周期或真实收益。结果由用户手动录入，可能存在选样偏差。本工具不自动交易，也不提供投资建议。

## 数据保护与兼容

- 沿用旧版本的 `reverse-signal:v1` 存储键；有效的旧记录和旧版 JSON 数组可以直接读取。
- 新备份采用 `{ "version": 2, "signals": [...] }` 格式，附带导出时间。
- 导入先校验全部记录，再合并。格式错误时不导入任何记录；重复 ID 或相同内容会跳过，不覆盖现有记录。
- 每个导入文件和新保存的完整备份最多 2 MB，记录总数最多 5,000 条。原话最多 10,000 字。保存前检查完整备份大小，避免生成无法重新导入的新备份。
- 保存失败会提示，原有记录和未保存的表单保留，不会假报保存成功。
- 无法读取旧数据时暂停写入，仍可导出原始备份，避免用空列表覆盖旧数据。
- 其他窗口修改存储时，当前页暂停写入。刷新后再编辑，避免覆盖其他窗口的修改。
- 页面用 DOM 文本节点显示记录，不把导入内容作为 HTML 执行。

数据存在当前浏览器的 localStorage，**不会自动上传 GitHub，也不会跨设备同步**。清理浏览器数据、无痕模式退出、更换浏览器或改变网站地址，都可能导致原数据不可见。直接打开本地文件时，浏览器也可能按文件路径隔离数据。更新或移动文件前先导出备份。

## 链接识别与隐私

链接识别依次尝试 FxTwitter 和 VxTwitter 第三方服务，每次请求最多等待 8 秒。点击识别时，会向服务发送推文作者名和推文 ID；不发送已有档案。服务可能因为网络、访问限制、接口变化或跨域限制而失败，仍可手动记录。

识别只是关键词辅助：成功读取后，多个标的、方向冲突或不确定时保持“待确认”，不会沿用上一条的标的或方向。读取失败保留原有草稿，不会把新链接和旧正文拼在一起；空白表单会保留链接供手动录入。新请求、手动输入或切换编辑会阻止旧请求回写。讽刺、否定和复杂语义仍可能识别错误，请核对原文。

## 开发与测试

应用本身没有运行时依赖，可直接静态托管。开发测试需要 [Node.js LTS](https://nodejs.org/)。

```powershell
npm install
npm test
```

`core.js` 包含校验、合并、统计和推文解析；`app.js` 管理交互；`index.html` 和 `style.css` 为界面。测试包括旧版数据兼容、异常备份、重复记录、统计边界、编辑后重新验证、撤销顺序、草稿保护、搜索与分页。
