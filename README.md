# 反指看板 · KOL 反向指标追踪器

> 「他喊多，你就空；他喊空，你就多。」
> —— 一条被市场反复验证的真理

一个**纯前端、零依赖、打开即用**的网页小工具：记录某个 KOL / 大V 的喊单，自动算出他的**「反指星级」**和**「反向操作置信度」**。

不需要后端，不需要数据库，数据存在你浏览器的 `localStorage` 里。整个项目就三个文件（`index.html` / `style.css` / `app.js`），丢到任意静态托管（GitHub Pages / Vercel / 直接双击打开）都能跑。

---

## ✨ 功能

- 📋 **记录喊单**：KOL 名、标的、方向（多/空）、参考价、原话备注
- 🌟 **反指星级**：根据他「错的概率」自动计算 0–18 星（凌晨三点的冥灯可达十八星）
- 📊 **反向置信度**：按他反向操作的胜率，一眼看出该不该反着来
- 🏅 **反指证书**：一键生成可截图分享的「反向指标认证证书」，发群里嘲讽专用
- 🔍 **多 KOL 管理**：下拉筛选，分别追踪不同反向源
- 💾 **导入 / 导出 JSON**：换浏览器、备份、分享数据都方便
- 🎨 赛博朋克终端风 UI（带扫描线 + glitch 标题）

## 🚀 使用方法

### 方式一：直接打开
双击 `index.html` 即可使用（数据存本地浏览器）。

### 方式二：部署到 GitHub Pages
```bash
git clone <你的仓库>
# 把 index.html / style.css / app.js 放进去
git add . && git commit -m "add reverse-signal" && git push
# Settings → Pages → 选 main 分支 → 完成
```

### 日常用法
1. 在「记录一次喊单」里填好 KOL 名、标的、方向，点录入
2. 等市场给结果，在列表里点「他赢」或「他亏」
3. 顶部统计会自动更新反指星级与反向置信度
4. 攒够样本后，去「生成反指证书」截图发群里

## 🧮 计算逻辑（严肃版）

| 指标 | 定义 |
|------|------|
| **他错的概率** | `他亏的次数 / 已验证总数` |
| **反向置信度** | = 他错的概率（你反向操作的预期胜率） |
| **反指星级** | `min(18, round(他错的概率 × 20))`，90% 错率 = 18 星 |
| **实际正确率** | `他赢的次数 / 已验证总数` |

分级称呼：
- 0 星 —— 尚未认证
- 1–2 星 —— 疑似随机波动
- 3–5 星 —— 初露反指锋芒
- 6–9 星 —— 稳定反向输出
- 10–13 星 —— 资深反向指标
- 14–17 星 —— 殿堂级反指
- **18 星 —— 历史级反指**

## 🤔 这玩意儿有啥用？

1. **自我娱乐 & 嘲讽**：把那些「一喊就反向」的 KOL 拉出来公开处刑。
2. **反讽研究**：客观统计某信号源的历史准确率，避免被幸存者偏差带节奏。
3. **交易纪律提醒**：当你忍不住想跟单时，先看一眼他的星级。

> ⚠️ 免责声明：本工具仅供娱乐与反讽研究，不构成任何投资建议。市场有风险，反向需谨慎。真要交易，请遵守你自己的纪律手册。
